Installation & Setup Guide

Everything you need to get Magic Gamepad up and running on your devices.

Download and Install the App

  • Download the desktop app from the provided link or by searching on Google: download
  • Open the setup file.

Click "I agree to the Licenses terms and conditions"

If you want to change the location, change the installation location and then click "Next."

Click "Install"

For the app to work properly, it's recommended to reboot your system. You can do this by checking the reboot option and clicking "Finish," or click "No, I will restart the computer later" and click "Finish" to complete the setup without rebooting.

Connecting Your Mobile to Desktop

For Wi-Fi, mobile hotspot, or USB tethering, both devices must be on the same local network (no internet connection is required). If you're using mobile hotspot or USB tethering, turn off mobile data or Wi-Fi on the Android device to ensure proper connection, or connect manually if needed. For Bluetooth, pair the devices before connecting through the app.

Open the desktop app.

You'll see the connection status and IP address displayed.

Connecting via Wi-Fi or Mobile Hotspot

On your mobile device, open the app.

Click "Wi-Fi Connect" then it will scan for nearby windows PC's running Magic Gamepad and display its local IP Address.

Select your Windows PC's local IP from the list to connect to your computer.

Or click "Manual IP" enter the displayed IP address, and click "Connect."

Now you can see a prompt with your device name asking for allowing connection. Click allow

Note: If you want to connect two or more devices, ensure all devices are connected to the same Wi-Fi network and repeat the connection steps for each device. If you are experiencing any delay, try connecting with USB tethering.

Connecting via USB Tethering

Connect a USB cable to your computer and open settings.

Click "Network and internet"

Click "Hotspot and tethering"

Enable USB tethering.

Note: This method may vary depending on the phone brand.
Important: If you want to connect multiple devices using USB tethering, make sure all desired devices are connected before opening the app. Ensure that Wi-Fi and mobile data are disabled while connecting the Android device to prevent any connection conflicts.

Open Magic Gamepad on both the computer and phone and connect as you would with the Wi-Fi method.

Connecting via Bluetooth on Windows PC

Pair the devices before connecting through the app. If already paired, you can skip this step.

Open the desktop app.

Open the mobile app.

Click "Bluetooth Connect" to select between different bluetooth mode.

Click the continue under the Magic Gamepad Server section

Select your desktop's name. After selecting, your phone will connect. Now you can start controlling your desktop.

Multiplayer Support

Once connected, MagicGamepad will display a gamepad UI along with a dialogue box that provides an option to select the player number/controller number. This allows for easy identification and configuration for multiple users or devices.

You can connect up to 4 devices and should ensure that you select different numbers for different users.
